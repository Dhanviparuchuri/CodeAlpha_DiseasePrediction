# Diabetes Risk Prediction

## Overview
This is a student machine-learning project that uses a dataset of health measurements to predict whether a person is classified as having diabetes. It includes a Streamlit interface for entering measurements and viewing a model prediction.

## Features
- Predicts a diabetes class from entered measurements
- Displays an estimated class-1 probability
- Shows model evaluation results and a confusion matrix
- Provides a simple Streamlit web interface

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Joblib
- Streamlit

## Run Locally
1. Install the required packages:
   `pip install -r requirements.txt`
2. Run the app:
   `streamlit run app.py`
